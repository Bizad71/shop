# سیستم فروش و انبار چندمغازه‌ای

این نسخه با Vite + JavaScript + Supabase ساخته شده است.

## امکانات
- ورود با نام کاربری و رمز
- تفکیک کامل اطلاعات هر مغازه
- نمایش نام مغازه بعد از ورود
- فروش با اسکن بارکد دوربین یا ورود دستی
- نمایش نام کالا، موجودی و تا دو قیمت
- انتخاب قیمت هنگام فروش
- کاهش موجودی بعد از ثبت فروش
- ورود کالا به انبار با بارکد، نام، تعداد و دو قیمت
- مدیریت کالاها و قیمت‌ها
- بخش مدیریت مدیر برای مدیریت مغازه‌ها/کاربران (از طریق Edge Function امن)

## راه‌اندازی
1. در Supabase یک پروژه بسازید.
2. فایل `supabase/schema.sql` را در SQL Editor اجرا کنید.
3. فایل `.env.example` را به `.env` تغییر دهید و URL و anon key پروژه را وارد کنید.
4. `npm install`
5. `npm run dev`

### ایجاد اولین مدیر
برای اولین مدیر، از Supabase Dashboard یک کاربر Auth بسازید، سپس شناسه کاربر را در جدول `profiles` با role=`admin` ثبت کنید. بعد از آن، مدیر می‌تواند مغازه‌ها و کاربران را از پنل مدیریت ایجاد کند.

### ایجاد کاربر مغازه
تابع Edge Function داخل `supabase/functions/admin-create-shop-user` برای ساخت کاربر با Service Role است. کلید service role را هرگز داخل فرانت‌اند قرار ندهید.

### نکته بارکد
مرورگر باید HTTPS باشد (به‌جز localhost) تا دسترسی دوربین فعال شود. اگر BarcodeDetector در مرورگر پشتیبانی نشود، ورود دستی بارکد فعال می‌ماند.
